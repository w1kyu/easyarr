## 0. Key takeaways (details + citations in the sections below)

1. **qBittorrent auth:** dashboard (10.21.x) is covered by the subnet whitelist for API *and* proxied UI; **localhost clients (Sonarr/Radarr/Lidarr/Cleanuparr) are NOT** — `WebUI\LocalHostAuth` defaults to `true`; seed `LocalHostAuth=false`. 5.3.0 also supports `Authorization: Bearer qbt_…` API keys (`WebUI\APIKey`) and HTTP Basic.
2. **qBittorrent behind `/apps/qbittorrent/` (stripped):** UI is fully relative → works (enforce trailing slash). No base-path key exists. Keep `ReverseProxySupportEnabled=false` so XFF can never replace the dashboard IP in the whitelist check. CSRF compares `Origin`/`Referer` host:port with `Host` → the proxy must either preserve the browser `Host` or rewrite `Origin`/`Referer` consistently.
3. **qBittorrent API:** `setPreferences` = POST form `json=<obj>`; ATM default = `auto_tmm_enabled`; share-limit action is still int `max_ratio_act` (0 Stop,1 Remove,2 SuperSeed,3 RemoveWithContent); `createCategory` on an existing name → **409**.
4. **SABnzbd:** API works before the wizard; `url_base` (exact key) + non-stripping proxy works (app mounted at `/` and at `url_base`); setting `url_base` via API **auto-restarts** SABnzbd → seed it in the INI. `inet_exposure`/`local_ranges` are API-protected; defaults allow private IPs (10.21/16 ok) — but **XFF with a non-private browser IP (e.g. Tailscale) is rejected** → don't forward XFF.
5. **Unpackerr 1.0.1:** `/config/unpackerr.conf`, TOML `[sonarr.0]` tables (legacy `[[sonarr]]` still read), read once at start (restart for file changes). New built-in UI on :5656 is on by default and rewrites the config to store a generated password → set `[webserver] listen_addr=""` or `ui_password="noauth"` + `upstreams`.
6. **Cleanuparr 2.10.12:** UI/API only, SQLite in `/config`. All `/api` except `/api/auth/*` is 403 until setup → bootstrap via `POST /api/auth/setup/account` + `/setup/complete`, login → JWT → `GET /api/account/api-key` → `X-Api-Key`. `BASE_PATH` = prefix must be kept by the proxy and used for direct calls too (`/apps/cleanuparr/health`).

### 1.1 Authentication — request pipeline (order matters)

`WebApplication::processRequest` [webapplication.cpp#L682](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L682):

2. **CSRF check** (skipped for API-key requests and for `/` and `/index.html`) and **Host header validation** [webapplication.cpp#L701](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L701) → failure = `401 Unauthorized`.

4. Session: existing cookie `QBT_SID_<port>` (name = prefix + WebUI port [webapplication.cpp#L506](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L506), so `QBT_SID_8090`), else **if `isAuthNeeded()` is false a session is started automatically**, else HTTP Basic credentials are accepted [webapplication.cpp#L808](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L808) (WebAPI 2.15.0 [WebAPI_Changelog.md#L130](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/WebAPI_Changelog.md#L130)).
5. API calls without a session (and not a public API such as `auth/login`) → `403 Forbidden` [webapplication.cpp#L328](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L328).

`isAuthNeeded()` [webapplication.cpp#L858](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L858):
```cpp
if (!m_isLocalAuthEnabled && m_clientAddress.isLoopback()) return false;     // WebUI\LocalHostAuth=false
```

`isIPInSubnets` also matches IPv4-mapped IPv6 forms (`::ffff:10.21.x.y`) [net.cpp#L105](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/utils/net.cpp#L105).

**Answers:**
- **Dashboard (source IP in 10.21.0.0/16, reverse-proxy support OFF):** whitelisted → no auth needed for *every* request, API and WebUI files alike. ✅ Nothing to log in to; just call the API. (Each cookie-less request creates a new session, see 1.6.)
- **Sonarr/Radarr/Lidarr/Cleanuparr via `localhost:8090` (shared netns):** source is `127.0.0.1`/`::1` → *not* in 10.21.0.0/16. `WebUI\LocalHostAuth` defaults to **true** [preferences.cpp#L789](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L789), i.e. localhost **does need auth by default**. Fix (pick one, first is simplest): seed `[WebUI] LocalHostAuth=false` (API key `bypass_local_auth=true` [appcontroller.cpp#L355](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/api/appcontroller.cpp#L355)), or add `127.0.0.0/8, ::1/128` to `AuthSubnetWhitelist`, or give clients credentials / the API key.
- Whitelist defaults: `AuthSubnetWhitelistEnabled=false` [preferences.cpp#L802](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L802); list is a QStringList of CIDRs [preferences.cpp#L815](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L815) (INI: `AuthSubnetWhitelist=10.21.0.0/16` or comma-separated for several; API: newline-separated string in `bypass_auth_subnet_whitelist`).
- If neither bypass applies and no password is set, qBittorrent generates a **temporary password printed to the log** each start [application.cpp#L1045](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/app/application.cpp#L1045).

### 1.4 Reverse proxy under `/apps/qbittorrent/` (prefix stripped)

**Relative URLs:** WebUI assets and XHRs are relative (`fetch("api/v2/auth/login")` [login.js#L38](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/www/public/scripts/login.js#L38), `fetch("api/v2/torrents/createCategory")` [newcategory.html#L345](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/www/private/newcategory.html#L345)); a grep of `src/webui/www` (excluding vendored `lib/`) finds no root-absolute `href`/`src`/`fetch("/…")`; redirects are `location.replace(location)`. Static files are served by path from `/public` or `/private` [webapplication.cpp#L193](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L193). ⇒ Prefix stripping works, **provided the browser URL ends with a slash** (`/apps/qbittorrent/`); redirect `/apps/qbittorrent` → `/apps/qbittorrent/` in the dashboard, exactly like the wiki's `location /qbt/ { proxy_pass http://127.0.0.1:30000/; }` [wiki NGINX-Reverse-Proxy-for-Web-UI.md L6](https://github.com/qbittorrent/qBittorrent/wiki/NGINX-Reverse-Proxy-for-Web-UI/a998759f0b6db4876432d25e989266bcb07fceb8).

**No base-path setting exists (Q5).** The only path-related WebUI prefs are `AlternativeUIEnabled`/`RootFolder` (alt UI files) — none changes the URL prefix; the session cookie is always `Path=/` [webapplication.cpp#L398](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L398) (scoped to the whole Umbrel origin — harmless).

**CSRF (`WebUI\CSRFProtection`, default true [preferences.cpp#L999](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L999))** — [webapplication.cpp#L969](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L969):
- target origin = `Host` header, or `X-Forwarded-Host` (falling back to `Host`) **only if reverse-proxy support is enabled** [webapplication.cpp#L981](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L981);
- if the browser sends `Sec-Fetch-Site`, only `same-origin`/`none` pass and Host is not consulted [webapplication.cpp#L988](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L988) (browsers send it only to trustworthy origins: HTTPS or localhost — so **not** on `http://umbrel.local`);
- else `Origin` (if present) must equal target in host **and port** (scheme ignored); else `Referer`; neither present ⇒ allowed (server-side API clients pass).
- failure ⇒ `401` and log line "Origin header & Target origin mismatch".

⇒ If the dashboard rewrites `Host` to `w1kyu-easyarr_vpn_1:8090` while the browser's `Origin`/`Referer` say `umbrel.local:<port>`, every UI XHR (qBittorrent sets `Referrer-Policy: same-origin` [webapplication.cpp#L537](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L537), so same-origin GETs carry `Referer` too) fails with 401. Options:
  1. **Preserve the browser's `Host`** when proxying (HostHeaderValidation is already off, so any Host is accepted [webapplication.cpp#L1035](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L1035) / default on [preferences.cpp#L1025](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L1025)). Works as long as the Host the dashboard receives equals the browser's Origin host:port (depends on Umbrel's app proxy — see Doubts).
  2. **Robust:** dashboard sets `Host: w1kyu-easyarr_vpn_1:8090` *and* rewrites `Origin`/`Referer` to `http://w1kyu-easyarr_vpn_1:8090/…` (or strips them) after doing its own same-origin check. The wiki calls header stripping "discouraged" because it nullifies qBittorrent's CSRF check [wiki NGINX-Reverse-Proxy-for-Web-UI.md L39](https://github.com/qbittorrent/qBittorrent/wiki/NGINX-Reverse-Proxy-for-Web-UI/a998759f0b6db4876432d25e989266bcb07fceb8) — acceptable only if the dashboard enforces same-origin itself.
  3. Last resort: `WebUI\CSRFProtection=false` (then the cookie gets no SameSite attribute unless Secure [webapplication.cpp#L765](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L765)).

**Reverse-proxy support and the whitelist (important):** `WebUI\ReverseProxySupportEnabled` (default false [preferences.cpp#L1129](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L1129)) + `WebUI\TrustedReverseProxiesList` (`;`-separated IPs/CIDRs; bare IP ⇒ /32 or /128; empty/invalid list ⇒ feature silently off) [webapplication.cpp#L574](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L574) [webapplication.cpp#L602](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L602). When on, the client IP is resolved from `X-Forwarded-For` [webapplication.cpp#L1070](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L1070) [net.cpp#L212](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/utils/net.cpp#L212): only if the TCP peer is a trusted proxy, walking the XFF list right-to-left and returning the first hop that is *not* a trusted proxy. With RP support on and a proxy that appends the browser's IP (e.g. `192.168.1.20` or Tailscale `100.x`), that IP becomes `m_clientAddress` → not in `10.21.0.0/16` → whitelist bypass lost → login page / 403. **Safe configuration:** keep `ReverseProxySupportEnabled=false` (XFF is then ignored entirely and the peer = dashboard container IP is checked against the whitelist) — this also means a browser cannot spoof XFF. The only things lost are correct client IPs in qBittorrent's log/ban list and `X-Forwarded-Host`/`X-Forwarded-Proto` awareness. If it is ever enabled, the dashboard must *not* send `X-Forwarded-For` (or must overwrite it with its own address).

**Headers the proxy should send:** with RP support off, qBittorrent reads only `Host`, `Origin`, `Referer`, `Sec-Fetch-Site`, `Cookie`, `Authorization`. Send `Host` per option 1/2 above; `X-Forwarded-*` are unnecessary (wiki sets `Host $proxy_host`, `X-Forwarded-For`, `X-Forwarded-Host $http_host`, `X-Forwarded-Proto` [wiki NGINX-Reverse-Proxy-for-Web-UI.md L11](https://github.com/qbittorrent/qBittorrent/wiki/NGINX-Reverse-Proxy-for-Web-UI/a998759f0b6db4876432d25e989266bcb07fceb8) — that recipe assumes RP support is ON so that `X-Forwarded-Host` is used as CSRF target; it is not suitable together with the subnet whitelist, see above).

**Clickjacking (`WebUI\ClickjackingProtection`, default true [preferences.cpp#L986](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L986)):** adds `X-Frame-Options: SAMEORIGIN` [webapplication.cpp#L542](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L542) and CSP `frame-ancestors 'self'` [webapplication.cpp#L548](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L548). **Secure cookie (`WebUI\SecureCookie`, default true [preferences.cpp#L1012](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L1012)):** the `Secure` flag is only set when the origin is trustworthy = built-in HTTPS, or RP support on + `X-Forwarded-Proto: https` [webapplication.cpp#L952](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L952). **Recommended qBittorrent.conf `[WebUI]` block for EasyArr** (owned keys only):
```ini
[WebUI]
Port=8090

AuthSubnetWhitelistEnabled=true
AuthSubnetWhitelist=10.21.0.0/16

```
`LocalHostAuth=false` → arr apps/Cleanuparr via localhost; whitelist → dashboard; `ReverseProxySupportEnabled=false` keeps XFF out of the client-IP decision; with CSRF on, the dashboard proxy must make `Origin`/`Referer` match `Host`. Optional `APIKey=qbt_<28 chars>` for Bearer auth (dashboard/Cleanuparr). No inline comments in this file (QSettings INI has no inline-comment syntax; text after `;` would become part of the value).

### 1.6 Session churn
Every cookie-less, bypass-authenticated request starts a new session; sessions are capped by `WebUI\SessionsCountLimit` (default 15 [preferences.cpp#L973](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/base/preferences.cpp#L973)) and the oldest is evicted [webapplication.cpp#L895](https://github.com/qbittorrent/qBittorrent/blob/9213075dd5f7b352208361c6a84c1c115efc898e/src/webui/webapplication.cpp#L895). Harmless for bypassed clients (they get a new one), but it can evict a credential-based session. Have the wiring engine keep the `QBT_SID_8090` cookie between calls, or use the Bearer API key (one key-bound session).

### 2.5 Access control: `inet_exposure`, `local_ranges`, Host check, XFF

`check_access(access_type)` [interface.py#L214](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L214): allowed if `access_type <= inet_exposure`; otherwise the TCP peer must be loopback or "local". "Local" = in `local_ranges` if that list is non-empty, else **any private address** per Python `ipaddress.is_private` (minus loopback/0.0.0.0/broadcast) [misc.py#L1307](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/misc.py#L1307) [misc.py#L1292](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/misc.py#L1292). `10.21.0.0/16` is RFC1918 → the dashboard (and `127.0.0.1` Sonarr) pass with the default `inet_exposure=0`, `local_ranges=[]`. ✅

XFF: if the peer is allowed **and** `verify_xff_header` is on and the request carries `X-Forwarded-For`, then **every** XFF entry must also be local/loopback, otherwise 403 [interface.py#L234](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L234). A browser on Tailscale (`100.64.0.0/10`, not `is_private`) or any public IP in XFF ⇒ "External internet access denied". ⇒ **The dashboard proxy should not send `X-Forwarded-For` to SABnzbd** (or EasyArr seeds `verify_xff_header=0`). XFF is otherwise only used to pick the IP for login cookies [interface.py#L288](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L288) (irrelevant without username/password).

Host check `check_hostname()` [interface.py#L246](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L246) is the **only** Host-based check (no Origin/Referer/CSRF checks exist in SABnzbd — grep for `Origin`/`Referer` in `sabnzbd/*.py` finds none). Skipped entirely when `username`+`password` are set [interface.py#L252](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L252). Otherwise the `Host` (port stripped) must be `localhost`, an IPv4/IPv6 literal, in `host_whitelist`, or end in `.local` [interface.py#L274](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L274). Applies to UI and API (incl. `mode=version`). Sonarr → `Host: localhost:8080` ✅; dashboard → `Host: w1kyu-easyarr_vpn_1:8080` ✅ (seeded). For proxied browser traffic either forward the original Host (fine for `umbrel.local` or an IP, **403 for e.g. a Tailscale MagicDNS name or custom domain**) or — simpler and safe because SABnzbd has no Origin check — rewrite `Host` to `w1kyu-easyarr_vpn_1:8080`.

### 2.6 `url_base` behind a non-stripping proxy

The app is mounted **twice**, at `/` and at `url_base` [SABnzbd.py#L1346](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/SABnzbd.py#L1346) (next line mounts `url_base`), with `cherrypy.Application.relative_urls = "server"` [SABnzbd.py#L1345](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/SABnzbd.py#L1345) (redirect `Location`s are path-only, no host). Server-side redirects prepend `url_base` (`Raiser` [interface.py#L450](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L450), wizard redirect [interface.py#L511](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L511)). Templates and JS use relative URLs (`./static/…` [main.tmpl#L36](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/interfaces/Glitter/templates/main.tmpl#L36), `url: "./api"` [glitter.basic.js#L32](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/interfaces/Glitter/templates/static/javascripts/glitter.basic.js#L32)).
⇒ **`url_base=/apps/sabnzbd` + proxy forwarding `/apps/sabnzbd/...` unchanged works**, and server redirects land under the prefix. With a *stripping* proxy and empty `url_base`, the wizard/login redirects would go to `/wizard/` at the Umbrel root — broken. The API stays reachable at both `/api` and `/apps/sabnzbd/api`, so the wiring engine can keep using `http://w1kyu-easyarr_vpn_1:8080/api` and Sonarr `http://localhost:8080` (url base field may stay empty). Changing `url_base` needs a restart (automatic when set via API, see 2.4). `/api` sends `Access-Control-Allow-Origin: *` [SABnzbd.py#L1332](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/SABnzbd.py#L1332).

Caveat: the wizard's final page builds its "go to SABnzbd" link from `cherrypy.request.base` (scheme + Host header) + `url_base` [interface.py#L671](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L671) — with a rewritten Host it would point at `http://w1kyu-easyarr_vpn_1:8080/apps/sabnzbd` (cosmetic, but a dead link for the user).

### 2.7 First-run wizard vs API
The wizard is only a redirect in `MainPage.index` (the UI root) when **no servers are configured** (unless `?skip_wizard=1`) [interface.py#L484](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L484). The `/api` handler has no such check [interface.py#L523](https://github.com/sabnzbd/sabnzbd/blob/a647f73426cb70ad60ae7964b96c2d5e939b4727/sabnzbd/interface.py#L523) ⇒ **the API is fully usable before the wizard**; once the wiring engine creates a server via `set_config section=servers`, the UI root stops redirecting. With `url_base=/apps/sabnzbd` the redirect target is `/apps/sabnzbd/wizard/` — works through the non-stripping proxy.

Image `ghcr.io/unpackerr/unpackerr` runs `/unpackerr` and `EXPOSE 5656` [Dockerfile#L56](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/Dockerfile#L56). **v1.0 is a big change vs 0.x**: instance lists became TOML *tables keyed by slug* (`[sonarr.0]`), and a built-in web UI/API on `0.0.0.0:5656` is **on by default** [start.go#L176](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/start.go#L176).

### 3.1 Config file location & loading
- Search order on Linux/Docker: `-c` flag path, then `/etc/unpackerr/unpackerr.conf`, **`/config/unpackerr.conf`**, `/usr/local/etc/unpackerr/unpackerr.conf`, `~/.unpackerr/unpackerr.conf`, `./unpackerr.conf` [cnfgfile.go#L113](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L113) [cnfgfile.go#L141](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L141); first existing file wins [cnfgfile.go#L37](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L37).
- If none exists and the process runs in Docker (`/.dockerenv` [cnfgfile.go#L518](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L518)) with a `/config` dir, it **creates `/config/unpackerr.conf` from the example template** [cnfgfile.go#L237](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L237).
- Then env vars (prefix `UN`, [start.go#L147](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/start.go#L147)) are overlaid on the in-memory config only — not written to the file [cnfgfile.go#L73](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L73).
- **Config is read once at startup.** No file watcher; `SIGHUP` only reopens log files [logs.go#L187](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/logs.go#L187). ⇒ a file EasyArr writes must exist before start; later file edits need a container restart. Live changes are possible through the HTTP API (`PUT /api/config/{section}` [api.go#L51](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/api.go#L51), response `{"status":"ok","restartRequired":bool}` [configput.go#L31](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/configput.go#L31)); starr sections (`sonarr`, `radarr`, `lidarr`…) apply without restart [configput.go#L86](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/configput.go#L86), while listen/TLS/urlbase changes need one [configput.go#L511](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/configput.go#L511) (Unpackerr re-execs itself when idle [restart.go#L11](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/restart.go#L11)). That API requires UI auth/API key (§3.4).

### 3.2 TOML keys (`[sonarr.<slug>]`, `[radarr.<slug>]`, `[lidarr.<slug>]`)
Top-level struct [apps.go#L68](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/apps.go#L68) (`sonarr`/`radarr`/`lidarr` are `InstanceMap` [apps.go#L95](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/apps.go#L95)). Legacy 0.x `[[sonarr]]` arrays are still accepted and converted to keys `"0"`, `"1"`… [instancemap.go#L16](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/instancemap.go#L16). Example says so explicitly [unpackerr.conf.example#L194](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L194) [unpackerr.conf.example#L206](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L206).

Per-instance keys = `starr.Config` (`url`, `api_key`, `http_user`, `http_pass`, `username`, `password`) [starr.go#L50](https://github.com/golift/starr/blob/a621386e6faf8692c92229955a62f2fcd24e7bb4/starr.go#L50) (golift/starr) + `StarrConfig` (`name`, `paths`, `protocols`, `delete_orig`, `delete_delay`, `syncthing`, `valid_ssl`, `timeout`, `max_bytes`) [handlers.go#L22](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/handlers.go#L22).
- `url`: full base URL **including any URL base**, must start with `http://`/`https://` [cnfgfile.go#L595](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L595); e.g. `http://localhost:8989` (Sonarr without url base) or `http://localhost:8989/sonarr`.
- `api_key`: required, ≥ 32 chars (`apiKeyMinLength = 32`) [cnfgfile.go#L610](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L610) [apps.go#L30](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/apps.go#L30); missing url/key ⇒ instance skipped with an error log.
- `paths`: fallback download roots if the path Sonarr reports isn't accessible; default `["/downloads"]` [cnfgfile.go#L574](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L574) [build_other.go#L7](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/build_other.go#L7) → set to EasyArr's real paths.
- `protocols`: default `"torrent,TorrentDownloadProtocol"` [apps.go#L29](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/apps.go#L29); add `usenet,UsenetDownloadProtocol` to also process SABnzbd items [unpackerr.conf.example#L232](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L232) (usually unnecessary: SABnzbd unpacks itself).
- `delete_orig` default false (keep false for torrents [unpackerr.conf.example#L240](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L240)).

### 3.3 Env vars
`UN_<SECTION>_<SLUG>_<KEY>` [MANUAL.md#L30](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/MANUAL.md#L30), e.g. `UN_SONARR_0_URL`, `UN_SONARR_0_API_KEY`, `UN_SONARR_0_PATHS_0`, `UN_SONARR_0_PROTOCOLS` [docker-compose.yml#L63](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/docker-compose.yml#L63) [docker-compose.yml#L69](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/docker-compose.yml#L69); webserver: `UN_WEBSERVER_LISTEN_ADDR`, `UN_WEBSERVER_URLBASE`, `UN_WEBSERVER_UPSTREAMS` [docker-compose.yml#L49](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/docker-compose.yml#L49).

**Which is better for EasyArr?** Env vars are compose-static — the arr API keys are only known after the arr apps generated them, so env vars would require compose templating with secrets. **A TOML file written by the init container before Unpackerr starts is better** (and supports later live edits through the API if desired). But note §3.4: Unpackerr *rewrites* the file itself in some cases, so the init must only manage owned keys (re-render whole owned sections) and tolerate Unpackerr's own rendering.

### 3.4 Built-in web UI / auth (new in 1.0) — affects the config file
- HTTP server runs whenever `[webserver] listen_addr` is non-empty [webserver.go#L54](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/webserver.go#L54); default `0.0.0.0:5656`.
- `ui_password` empty ⇒ Unpackerr **generates a temporary password, logs it once** [password.go#L429](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/password.go#L429) **and persists the hash by re-rendering the whole config file** [password.go#L332](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/password.go#L332) [password.go#L384](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/password.go#L384) [cnfgfile.go#L282](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/cnfgfile.go#L282). Same for a plaintext `user:pass`. (Comments in the EasyArr-written file would be lost; content stays equivalent.)
- To avoid both the rewrite and a login, either disable the server (`listen_addr = ""`) or set `ui_password = "noauth"` together with `upstreams = ["10.21.0.0/16"]`: `noauth`/`webauth:<Header>` count as proxy auth and are honoured only for requests whose peer is in `upstreams` [auth.go#L252](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/auth.go#L252) [auth.go#L261](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/auth.go#L261) [password.go#L109](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/password.go#L109) [unpackerr.conf.example#L126](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L126) [unpackerr.conf.example#L160](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L160). `urlbase` (default `/`) serves the UI under a prefix (non-stripping proxy, e.g. `/apps/unpackerr`) [unpackerr.conf.example#L155](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/examples/unpackerr.conf.example#L155) [webserver.go#L179](https://github.com/Unpackerr/unpackerr/blob/f58fab2935e90b65c61b3722fdbad394f71ee0dc/pkg/unpackerr/webserver.go#L179).

- When set, a middleware **404s every request whose path does not start with BASE_PATH**, except `/` which is redirected to `BASE_PATH/` [Program.cs#L142](https://github.com/Cleanuparr/Cleanuparr/blob/b7d5918fbb4813427ce8c07f23830a12a1561c77/code/backend/Cleanuparr.Api/Program.cs#L142), then `UsePathBase(basePath)` [Program.cs#L148](https://github.com/Cleanuparr/Cleanuparr/blob/b7d5918fbb4813427ce8c07f23830a12a1561c77/code/backend/Cleanuparr.Api/Program.cs#L148).
