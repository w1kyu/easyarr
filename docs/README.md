# docs/

EasyArr's documentation, written in Markdown. The user guides are shown on GitHub, inside EasyArr
under **Help**, and collected in [llms.txt](../llms.txt) for AI assistants (SPEC §16).

- **User guides:** the pages in this folder and in [vpn/](vpn/README.md). Start with
  [Getting started](getting-started.md). Their order is set in [nav.json](nav.json).
- **Images:** [images/](images/), the only images the in-app help shows. Screenshots are made with
  `pnpm docs:shots`.
- **Developer docs:** [dev/](dev/architecture.md): architecture, development, releases, and the
  research notes behind the service integrations ([dev/research/](dev/research/servarr.md)).

How to write and check a guide: [Writing docs](dev/development.md#6-writing-docs).
